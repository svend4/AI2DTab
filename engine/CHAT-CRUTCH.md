# Костыли не к чату — вместо чата

Чат одномерен: одно окно внимания, порядок обязателен, каждый абзац снова тащит все предыдущие.
Стол двумерен: id живут сразу, LOOK режет все кластеры за один ход, BATCH принимает пачку без пересказа.

## Что нельзя (или слишком долго) делать в чате

| в чате | на столе |
|---|---|
| «кратко перескажи 30k» | `PLANT` ленту, `GRID` сразу показывает дыры |
| снова найти все ≠ | `LOOK ≠` / `DIFF` — список ACCEPT |
| принять по одному в прозе | `BATCH ACCEPT id; ACCEPT id` |
| не перепутать «Да» с фактом | type=session → REFUSE |
| «учти прошлую сессию» | sqlite `canon`, не контекст модели |
| параллельные темы | фильтр A/B/C/D, не новый абзац |

## Ходы модели (не эссе)

1. Сырьё пришло → `PLANT`, не саммари.
2. `GRID` — где сырьё, где канон, где session.
3. `DIFF` — что ещё raw; `≠` принять пачкой.
4. `JSON` — снимок для следующего агента, не проза в чат.
5. `FETCH` — новый вопрос, которого нет в каноне.
6. Запрет: не писать «итак, подведём итог» вместо `DUMP`.

Алфавит: STATUS LOOK PLANT ACCEPT TAKE RUN FETCH DUMP GRID DIFF JSON BATCH
