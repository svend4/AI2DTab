# Язык калькулятора

Множества (элементы = id):

- RAW, CANON — заряд конденсатора
- NEQ — именованный диапазон «≠»
- SESSION — не канон
- A B C D — кластеры
- OBS — наблюдения

Операции (сложение/вычитание множеств, не смыслов):

    SET NEQ
    SET NEQ ∩ C
    SET RAW \ SESSION
    SET CANON ∪ NEQ
    SET RAW \ SESSION \ NEQ

Знаки: `∩` (или `&`, `AND`), `∪` (или `|`, `OR`), `\` (или `MINUS`); слова пишутся заглавными и отдельно,
чтобы не резать идентификаторы вроде ORG1. В выражении может быть сколько угодно операций: оно читается слева
направо без приоритетов, `A \ B ∩ C` = `(A \ B) ∩ C`. Операнд — имя множества или идентификатор существующего
объекта; любое другое имя (`NEQQ`, `NOPE`) — ошибка «нет множества или объекта …», а не молча пустое множество.
Известное, но пустое множество (например `SESSION`, пока сессий нет) ошибкой не считается. В `ACCEPT` и `TAKE`
выражение узнаётся по знаку (`∩ ∪ \ & |`) или по голому имени множества; слова `AND`/`OR`/`MINUS` годятся только в `SET`.

Матрица: MATRIX = GRID, ячейка (кластер, тип) = |raw|/|canon|.
Умножение MATRIX A × B запрещено (MUL): это склейка кластеров.
Морфизм только редкий: PACKET (ребро links, не заполненная матрица).

    PACKET
    PACKET C A
    PACKET D001

Формулы: =NEQ  =NEQ∩C  =PACKET  =MATRIX  =COUNTIF(≠)

Макрос по множеству, не по списку из чата:

    FILL                 # ACCEPT NEQ ∩ RAW
    ACCEPT NEQ ∩ RAW
    ACCEPT NEQ ∩ C

    SWEEP                # TAKE SESSION
    TAKE SESSION
    TAKE RAW ∩ SESSION

Ячейка NEQ — не LIKE по body, а разбор заголовка:

    pred ≠ obj     длина обеих сторон ≥ 2
    Example: / Again: / Critical invariant:  — не ячейка

    NEQ / CELL     печать id, status, pred, rel, obj
    REPAIR         канон-мусор → снова raw
    FILL           только NEQ ∩ RAW; в отчёте ok / refuse / skip

Замена принятого. `TAKE` канон не снимает; пересмотренное решение заменяют, старое остаётся в истории:

    SUPERSEDE D001 BY D001B пришло письмо Минтруда
    SUPERSEDE D001 D001B             # BY можно опустить
    SUPERSEDE D001 UNDO ошиблись     # откат замены
    SET SUPERSEDED                   # что уже заменено

    D001 → superseded (из канона уходит), D001B принимается тут же, если ещё не канон;
    связь D001B -supersedes-> D001, причина в её примечании; видно в PACKET D001.
    Заменяют только канон. Заместитель — не rejected/superseded/session/tape и «похож» на старое:
    между ними есть связь, либо тот же тип и общее слово в заголовках. Иначе REFUSE с подсказкой
    WIRE новый старый related (защита от опечатки в id: SUPERSEDE D002 BY D001B).
    ACCEPT/TAKE замещённое не возвращают: назад только UNDO, с конца цепочки.
    check: замещённый объект без действующего заместителя — проблема.
    Глагол для человека: в меню сайта и в MCP картотеки его нет, а BATCH его пропускает (skip) — иначе список глаголов сайта
    обходился бы строкой «BATCH STATUS; SUPERSEDE …» (сайт проверяет только первое слово).
