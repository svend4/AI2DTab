# Exchange t002 (2026-09-17 19:53)

Обсуждение расширяет идею «биржи труда» (Enbek) до универсального оркестратора инновационных ресурсов: людей, AI-агентов, знаний, кода, данных, оборудования, денег и организаций. Граф должен быть исполняемым: он выполняет комбинаторный matching команд, устраняет дефицит ресурсов, автоматически собирает проект и запускает workflow, а результаты обновляют граф. Итоговая архитектура делится на три уровня (World Model, Intelligence, Execution), а название предлагается уточнить до Open Innovation Operating System.

## Claims
### AI Innovation Resource Orchestrator
- Система задумана не как «биржа труда 2.0», а как интеллектуальный оркестратор инновационных ресурсов, собирающий проект из людей, AI-агентов, знаний, кода, оборудования, денег и организаций. (t002 L11 [chat.md:L384-384])
- Центральный вопрос системы: какая комбинация людей, AI-агентов, знаний, программного кода, оборудования, денег и организаций способна решить проблему и как автоматически собрать из них работающий проект. (t002 L19 [chat.md:L392-392])
- Новизна конструкции состоит в том, что общим объектом оптимизации становятся одновременно Problem, People, AI, Knowledge, Code, Data, Equipment, Money, Organizations, Legal constraints и Time. (t002 L1074 [chat.md:L1447-1447])
- Ключевой переход — от информационного графа к самособирающимся и исполняемым проектам; полный цикл: Problem → Resource Graph → Matching → Project Assembly → Execution → Measured Result → Graph Update. (t002 L1112 [chat.md:L1485-1485])
### Innovation Knowledge Graph
- Граф содержит типы объектов: PERSON, AI_AGENT, SKILL, KNOWLEDGE, PROBLEM, TASK, PROJECT, REPOSITORY, SOFTWARE, DATASET, PAPER, PATENT, EQUIPMENT, LAB, COMPANY, UNIVERSITY, GRANT, INVESTOR, LOCATION, REGULATION, STANDARD, а между ними — сотни типов отношений. (t002 L49 [chat.md:L422-422])
- Граф сам по себе ничего не решает: его отличие от Википедии или базы данных в том, что он должен быть исполняемым. (t002 L120 [chat.md:L493-493])
- Существующие компоненты (Research Graph, Helikon, GitHub Innovation Graph, DCO NexaBridge) реализуют только части такой модели. (t002 L23 [chat.md:L396-396])
### Enbek [[n132]]
- Enbek решает задачу «какому человеку подходит какая работа?», тогда как предлагаемая система решает задачу сборки комбинации любых ресурсов. (t002 L13 [chat.md:L386-386])
- Предлагаемая идея существенно шире казахстанской системы занятости. (t002 L13 [chat.md:L386-386])
### combinatorial matching
- Matching в системе не парный (Person ↔ Job), а комбинаторный: группа людей, AI-агентов, репозиториев, лабораторий и грантов объединяется в проект; это также hypergraph matching, так как одна связь соединяет много сущностей. (t002 L328 [chat.md:L701-701])
### Score(C)
- Оценка комбинации Score(C) = w1·SkillFit + w2·KnowledgeFit + w3·Availability + w4·CostFit + w5·LocationFit + w6·Trust + w7·FundingFit − w8·Risk максимизируется системой при выборе комбинации ресурсов C. (t002 L366 [chat.md:L739-739])
- Система не обязана выбирать конфигурацию автоматически: она может показать несколько жизнеспособных вариантов и различия между ними. (t002 L395 [chat.md:L768-768])
### Resource Gap Resolution [[n113]]
- Skill Gap в Enbek заменяется Resource Gap: система сравнивает требуемые проектом ресурсы с имеющимися и выявляет дефицит, например optical engineer, €75k и test laboratory. (t002 L401 [chat.md:L774-774])
- При обнаружении дефицита система автоматически запускает поиск людей (People Agent), финансирования (Funding Agent) и инфраструктуры (Infrastructure Agent). (t002 L443 [chat.md:L816-816])
### Grant Agent
- Grant Agent сравнивает метаданные проекта с грантовыми программами (Horizon Europe, EIC, Eurostars, BMBF, SAB, DFG, Foundations) и выдаёт eligibility, topic fit, budget fit и срок подачи. (t002 L515 [chat.md:L888-888])
- Грант меняет структуру команды: если в требованиях гранта нет университетского партнёра, автоматически создаётся задача поиска лаборатории. (t002 L549 [chat.md:L922-922])
### Temporal Innovation Graph
- Граф динамический: состояние проекта меняется во времени (например, TRL 2 через три месяца становится TRL 4), поэтому Graph(t0) ≠ Graph(t1). (t002 L582 [chat.md:L955-955])
- Граф знает не только что существует, но и что существует сейчас, что появилось, что исчезло и что изменилось. (t002 L597 [chat.md:L970-970])
### Artificial Autonomous Technological Awareness
- Система имеет модель собственных и внешних технологических возможностей и может обнаруживать комбинации ресурсов, способные дать новый результат. (t002 L642 [chat.md:L1015-1015])
- Пример: статья, репозиторий, компания с проблемой, грант и исследователь образуют гипотезу нового проекта, которую агент обозначает как Potential project detected. (t002 L631 [chat.md:L1004-1004])
### Human–AI Resource Allocation
- AI-агенты могут занимать роли людей в проекте, и предметом matching становится распределение ресурсов между людьми и AI, а не только поиск специалистов. (t002 L892 [chat.md:L1265-1265])
- Пример распределения ролей: Literature review → AI agent; Patent search → AI agent + human check; PCB → engineer. (t002 L910 [chat.md:L1283-1283])
### World Model
- Архитектура делится на три уровня: Уровень I — World Model (Innovation Graph), Уровень II — Intelligence (AI Agents: search, matching, planning, prediction, gap analysis, team formation), Уровень III — Execution (MCP, n8n, Make, APIs, robots, software). (t002 L727 [chat.md:L1100-1100])
- Уровни образуют замкнутый цикл WORLD → MODEL → REASON → PLAN → ACT → OBSERVE → WORLD. (t002 L794 [chat.md:L1167-1167])
### One-click Project Formation
- Система за 30 секунд формирует PROJECT PACKAGE: проблему, prior art, статьи и патенты, решение, команду, AI-агентов, репозитории, датасеты, оборудование, лабораторию, оценку стоимости, гранты, timeline, анализ рисков, IP/licensing и первые эксперименты. (t002 L940 [chat.md:L1313-1313])
- Эта функция также называется Autonomous Project Assembly (автоматическая сборка проекта). (t002 L988 [chat.md:L1361-1361])
### Open Innovation Operating System
- Названия возможной системы по уровням: Innovation Knowledge Graph → Innovation Resource Graph → Innovation Matching Engine → Innovation Resource Orchestrator → Innovation Operating System. (t002 L1049 [chat.md:L1422-1422])
- Наиболее полные варианты названия: Open Innovation Operating System и AI-Orchestrated Virtual Technopark. (t002 L1064 [chat.md:L1437-1437])
