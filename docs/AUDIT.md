# Аудит AI2DTab (ветка `svend4-patch-1`, экспорт из Grok, 2 коммита)

Дата аудита: 2026-10-09. Проверено запуском: движок `engine/pm.py` в песочнице,
`npm ci`, `npm run typecheck`, чтение всех исходников и скриншотов QA.

## 0. Что это такое (в одном абзаце)

Приложение «Четыре такта» — стол для работы с длинными диалогами ИИ. Тезис:
чат одномерен (одно окно внимания, порядок обязателен), а работа требует
двумерной плоскости. Поток (L1 лента) нарезается на записи с семью полями
(L2 плоскость), человек принимает часть из них в канон (L3 память, sqlite),
машина ходит по id, а не по смыслу (L4 действие) и возвращает новое сырьё в
ленту. Язык управления — алфавит глаголов (`PLANT ACCEPT TAKE SET NEQ FILL
SWEEP GAP SETTLE WIRE PORT SPEC …`) с алгеброй множеств над id и «ячейками»
вида `pred ≠ obj`. Источник сырья — диалог ChatGPT на 344 тыс. строк
(81 ход, из них ~70 — «Да» / «Продолжение») про Enbek.kz и «Innovation OS».

## 2. Критичные находки (воспроизведены)

### 2.1 Повторная посадка молча теряет текст
`engine/pm.py:255-290` — `plant_text` даёт id по порядковому номеру абзаца
(`B1`, `Q2`, `C3`), а `upsert_raw` пропускает существующий id. Любая вторая
лента, в которой второй абзац — вопрос, получит `Q2` и будет пропущена как
«already». Проверка:

```
$ pm.py exec PLANT "первый текст\n\nвторой абзац с вопросом?"
$ pm.py exec PLANT "совсем другой текст\n\nдругой вопрос?"
skip Q1 already question/raw
n=1
```

### 2.2 Текст из строки команд схлопывается в один абзац
`engine/pm.py:636-639` — `line.split()` режет аргумент по любым пробельным
символам, включая `\n`, и потом склеивает через пробел. Разделитель абзацев
исчезает до того, как `plant_text` его увидит. Через UI это маскируется
записью во временный файл, через CLI/BATCH — нет.

### 2.3 Приложение привязано к одной песочнице
`src/lib/pm-api.ts:5-6,32,46` — пути `/workspace/engine/pm.py`,
`/workspace/engine/project-store.sqlite`, `/tmp/desk-tape.txt`, запуск
`python3` субпроцессом с таймаутом 12 с. На Vercel (целевая платформа по
`AGENTS.md`) нет python, нет записи в ФС, нет `/workspace`. Все четыре экрана
без движка пусты: «приборы · нет съёма».

### 2.4 Гонка на общем временном файле
`src/lib/pm-api.ts:46` — все посадки пишут в один `/tmp/desk-tape.txt`.
Две параллельные посадки перезапишут друг друга.

### 2.5 `npm ci` падает, `typecheck` красный на чистом клоне
- `package-lock.json` не соответствует `package.json` (ajv 6 vs 8) → `npm ci` EUSAGE.
- `src/lib/kit-api.ts:17-21` вызывает callback-`readFile` как синхронную функцию → 3 ошибки TS; в рантайме вернёт `undefined` и упадёт на `.length`.
- `tsconfig.json` `baseUrl` — TS 5.9 выдаёт ошибку TS5101.

## 4. Что сделано хорошо (сохранить)

- **Разделение raw / canon и REFUSE для session/tape.** «Да» не факт — это
  редкий и правильный барьер против самоподтверждения чата.
- **Алфавит глаголов вместо кнопок.** Один язык для человека, UI и агента;
  BATCH убирает пересказ.
- **SPEC из журнала.** Язык существует, пока им ходят; «новый глагол только
  при LIVE GAP ≥ 3» — рабочее правило против разрастания.
- **Приборы с красной зоной → GAP → SETTLE.** Замкнутая петля: диагностика
  сама сажает вопрос и сама его закрывает.
- **Запрет MUL.** Явное «не паять декартово произведение» — здоровая
  дисциплина против автосвязывания.
- **Дизайн-токены** (`src/styles.css`): спокойная монохромная система, IBM Plex.
