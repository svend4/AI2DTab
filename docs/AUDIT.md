## 0. Что это такое (в одном абзаце)

Приложение «Четыре такта» — стол для работы с длинными диалогами ИИ. Тезис:
чат одномерен (одно окно внимания, порядок обязателен), а работа требует
двумерной плоскости. Поток (L1 лента) нарезается на записи с семью полями
(L2 плоскость), человек принимает часть из них в канон (L3 память, sqlite),
машина ходит по id, а не по смыслу (L4 действие) и возвращает новое сырьё в
ленту. Язык управления — алфавит глаголов (`PLANT ACCEPT TAKE SET NEQ FILL
SWEEP GAP SETTLE WIRE PORT SPEC …`) с алгеброй множеств над id и «ячейками»
вида `pred ≠ obj`. Источник сырья — диалог ChatGPT на 344 тыс. строк
(81 ход, из них ~70 — «Да» / «Продолжение») про Enbek.kz и «Innovation OS».

## 2. Критичные находки (воспроизведены)

### 2.1 Повторная посадка молча теряет текст
`engine/pm.py:242-297` — `plant_text` (242-271) даёт id по порядковому номеру
абзаца (`B1`, `Q2`, `C3`), а `upsert_raw` (274-297) пропускает существующий
id. Любая вторая лента, в которой второй абзац — вопрос, получит `Q2` и будет
пропущена как «already». Так работает именно путь из UI: посадка через
L1 пишет ленту во временный файл и вызывает `PLANT --file`. Проверка на
чистой базе (`pm.py init`) двумя разными файлами:

```
$ cat file1.txt                       $ cat file2.txt
первый текст                          совсем другой текст

второй абзац с вопросом?              другой вопрос?

$ pm.py exec PLANT --file file1.txt
plant B1
plant Q2
n=2
$ pm.py exec PLANT --file file2.txt
skip B1 already observation/raw
skip Q2 already question/raw
n=2
```

Второй файл не посадил ни одной записи, хотя в нём ни слова из первого.

### 2.2 Текст из строки команд схлопывается в один абзац
`engine/pm.py:629-632` — `line.split()` режет аргумент по любым пробельным
символам, включая настоящий перевод строки, и потом склеивает через пробел.
Разделитель абзацев `\n\n` исчезает до того, как `plant_text` его увидит:
`PLANT "$(printf 'текст\n\nвопрос?')"` даёт `plant Q1 / n=1` — один абзац
вместо двух. Оговорка: литеральная последовательность из двух символов `\n`
(обратный слэш + n) выживает после `split()` и разворачивается в перевод
строки на `engine/pm.py:660`, так что через CLI/BATCH абзацы можно передать
только в таком экранированном виде. Через UI это маскируется записью во
временный файл.

### 2.5 `npm ci` падает, `typecheck` красный на чистом клоне
- `package-lock.json` не соответствует `package.json`: в lock только `ajv@6.15.0`, а дерево зависимостей требует `ajv@8.20.0` (плюс `fast-uri`, `json-schema-traverse@1`) → `npm ci` падает с EUSAGE ещё до установки.
- `src/lib/kit-api.ts:17-21` вызывает callback-`readFile` как синхронную функцию → 3 ошибки TS (TS2554, TS2339 ×2) на закреплённом TypeScript 5.9.3. В рантайме Node 22 такой вызов без колбэка не возвращает `undefined`, а синхронно бросает `ERR_INVALID_ARG_TYPE`; `catch` его глотает, цикл идёт дальше и функция заканчивается `throw new Error("path")`. Итог: любой файл, даже существующий, читается как «не удалось прочитать файл» (см. 3.8).
- `tsconfig.json:24` `baseUrl` — на закреплённом TypeScript 5.9.3 ошибки не даёт (typecheck показывает ровно 3 ошибки выше). TS5101 («baseUrl устарел») появляется только когда `node_modules` отсутствует и `npx tsc` подтягивает свежий TypeScript 6.x. `baseUrl` всё равно стоит убрать — `paths` работают без него, а в следующих мажорных версиях опция удалена.

### 2.6 Обход каталога через публичную серверную функцию
`src/lib/pm-api.ts:45` — проверка пути к файлу посадки сделана префиксом:
`data.file.startsWith("/workspace/engine/")`. Строка
`/workspace/engine/../../etc/passwd` проверку проходит (`path.resolve` даёт
`/etc/passwd`), а `plant_file` (`engine/pm.py:300-312`) читает любой файл
сервера и сажает его содержимое в базу как записи L2. `pmExec` — публичный
POST без авторизации. Воспроизведено: в node `startsWith` возвращает `true`
для такого пути; в движке `PLANT --file <engine>/../../../etc/hostname` даёт
`plant B1`, после чего `LOOK` показывает имя хоста как `observation/raw`.

## 4. Что сделано хорошо (сохранить)

- **Разделение raw / canon и REFUSE для session/tape.** «Да» не факт — это
  редкий и правильный барьер против самоподтверждения чата.
- **Алфавит глаголов вместо кнопок.** Один язык для человека, UI и агента;
  BATCH убирает пересказ.
- **SPEC из журнала.** Язык существует, пока им ходят; «новый глагол только
  при LIVE GAP ≥ 3» — рабочее правило против разрастания.
- **Приборы с красной зоной → GAP → SETTLE.** Замкнутая петля: диагностика
  сама сажает вопрос и сама его закрывает.
- **Запрет MUL.** Явное «не паять декартово произведение» — здоровая
  дисциплина против автосвязывания.
- **Дизайн-токены** (`src/styles.css`): спокойная монохромная система, IBM Plex.
