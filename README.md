# AI2DTab — стол для долгих диалогов с ИИ

Чат одномерен: одно окно внимания, порядок обязателен, каждый ход тащит за
собой все предыдущие. Стол двумерен: записи с id живут сразу, срез режет все
темы за один ход, человек принимает пачкой, машина ходит по id, а не по смыслу.

```
L1 лента  ──PLANT──▶  L2 плоскость  ──ACCEPT──▶  L3 канон  ──RUN──▶  L4 действие
   ▲                                                                   │
   └───────────────────────── FETCH (новый вопрос) ◀───────────────────┘
```

## Ветка v2.1 (эта)

- `src/engine/` — движок на TypeScript, чистые функции над JSON-книгой;
  работает в браузере, в Node и в тестах. Тот же алфавит, что в v1, плюс
  `UNDO` ходом, `ACTOR`, `MERGE`/`DIFFBOOK`, `CHAIN`, `TURN`, `REPAIR id`.
  Нарезка понимает экспорт диалога с цитатами и секциями `# N.`.
- `src/lib/storage.ts` — IndexedDB с откатом на localStorage; `src/lib/desk.ts`
  — стол в браузере.
- `src/routes/` — пять экранов: `/` лента, `/l2` плоскость, `/l3` память,
  `/l4` действие, `/cycle` закон такта.
- `docs/AUDIT.md` — аудит исходной версии (с errata после встречной
  проверки); `docs/STAGE.md` — на какой стадии идея, методы, концепция,
  техника; `docs/V2.md` — что изменено, плюсы/минусы, спорные места, новые
  идеи, §7 — что исправило ревью; `docs/PROTOCOL.md` — как агенту ходить по
  столу; `docs/CORPUS.md` — эксперимент на исходном диалоге (4,7 МБ) и
  точность классификатора.
- `engine/` — исходный Python-движок v1 (sqlite). Оставлен как справочная
  реализация; приложение его больше не вызывает.
- `attachments/` — исходный диалог ChatGPT (344 тыс. строк), из которого
  выросла идея. `engine/samples/ont-l2.tsv` — 36 секций корпуса для посадки.

## Запуск

```bash
npm install
npm run dev          # http://localhost:8080
npm run test:engine  # тесты движка и хранилища
node --experimental-strip-types scripts/corpus-stats.mjs   # статистика корпуса
npm run typecheck && npm run lint && npm run build
```

Книга хранится в IndexedDB браузера (откат на localStorage); стартует с
семенем v1 (31 запись, 15 рёбер, 1 письмо). На L4 — экспорт JSON/TSV, импорт
JSON с заменой или слиянием и предпросмотром разницы.

## Алфавит (строка команд на любом экране, `HELP` — полный список)

```
PLANT text        посадить ленту            SET NEQ ∩ (RAW ∪ CANON) \ C
FILL              принять все ячейки ≠      WIRE a b rel   одно ребро
TAKE id|set       вычесть                   PROBE C A · CHAIN  кандидаты рёбер
UNDO              откат хода целиком        INSTR GAP SETTLE  приборы и красная зона
WHY id · TURN n   почему строка такая       NEXT SPEC JSON    ход, язык, снимок
ACTOR machine     машина не ставит канон    MERGE · DIFFBOOK  вторая книга
```
