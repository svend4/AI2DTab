# AI2DTab — рабочее пространство структурирования знаний

Экспериментальный веб-интерфейс для преобразования необработанного текста в структурированные записи и работы с ними на этапах L1–L4. В проект входят интерфейс на React/TypeScript и Python/SQLite-движок.

См. `engine/README.md` и `engine/LANG.md`.
