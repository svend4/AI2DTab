# AI2DTab — стол для долгих диалогов с ИИ

Чат одномерен: одно окно внимания, порядок обязателен, каждый ход тащит за
собой все предыдущие. Стол двумерен: записи с id живут сразу, срез режет все
темы за один ход, человек принимает пачкой, машина ходит по id, а не по смыслу.

```
L1 лента  ──PLANT──▶  L2 плоскость  ──ACCEPT──▶  L3 канон  ──RUN──▶  L4 действие
   ▲                                                                   │
   └───────────────────────── FETCH (новый вопрос) ◀───────────────────┘
```

## Ветка v2 (эта)

- `src/engine/` — движок на TypeScript, чистые функции над JSON-книгой;
  работает в браузере, в Node и в тестах. Тот же алфавит, что в v1.
- `src/routes/` — пять экранов: `/` лента, `/l2` плоскость, `/l3` память,
  `/l4` действие, `/cycle` закон такта.
- `docs/AUDIT.md` — аудит исходной версии; `docs/STAGE.md` — на какой стадии
  идея, методы, концепция, техника; `docs/V2.md` — что изменено, плюсы/минусы,
  спорные места, новые идеи; `docs/PROTOCOL.md` — как агенту ходить по столу.
- `engine/` — исходный Python-движок v1 (sqlite). Оставлен как справочная
  реализация; приложение его больше не вызывает.
- `attachments/` — исходный диалог ChatGPT (344 тыс. строк), из которого
  выросла идея. `engine/samples/ont-l2.tsv` — 36 секций корпуса для посадки.

## Запуск

```bash
npm install
npm run dev          # http://localhost:8080
npm run test:engine  # тесты движка
npm run typecheck && npm run lint && npm run build
```

Книга хранится в `localStorage` браузера; стартует с семенем v1 (31 запись,
15 рёбер). На L4 — экспорт/импорт JSON и TSV.
